# Камень-ножницы-бумага

Консольная игра на Python.

## Правила игры
- Камень побеждает ножницы
- Ножницы побеждают бумагу
- Бумага побеждает камень

## Как запустить
1. Установите Python 3
2. Откройте терминал в папке с игрой
3. Введите команду:
python rock_paper_scissors.py

## Управление
- камень или 1 — выбрать камень
- ножницы или 2 — выбрать ножницы
- бумага или 3 — выбрать бумагу
- счет — показать статистику
- выход — выйти из игры
